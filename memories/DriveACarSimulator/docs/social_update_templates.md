# Social update post templates

**Purpose:** Short, reusable shells for Discord, X, Roblox group posts, and creator captions. Swap bracketed placeholders; keep claims aligned with shipped build notes.  
**Tone:** Friendly and confident — clear wins, no fake urgency, no “best ever” hype. Pair with `docs/Phase4_TerminologyAndVoiceGlossary.md` for Driver / coins / gems wording.

---

## 1 — Patch highlight

**Headline hook:**  
Small update, clearer ride — here’s what changed in **Drive a Car Simulator** today.

**Beats:**
- **[Change 1]** — one sentence on what players will notice (feel or clarity, not jargon).
- **[Change 2]** — optional second fix or polish line if it’s in the patch.
- **Thanks** for the reports that helped us spot **[rough theme, e.g. HUD overlap / payout line]**.

**CTA:**  
Jump in, run a lap, and tell us how it feels on your device.

**Hashtags (optional):**  
`#Roblox` `#DriveACarSimulator` (add one world or feature tag only if it matches the patch, e.g. `#Phase4`)

**Hashtags (optional):**

## Quick copy checklist (before post)

- [ ] Claims match patch notes or store-approved copy — no invented % or prices.  
- [ ] CTA verb matches intent (claim / buy / redeem / equip / hatch) per `docs/CTAVerbConsistency.md`.  
- [ ] No “whale” framing for players; **Driver** / **coins** / **gems** per glossary.  
- [ ] Short enough for mobile — trim bullets if the platform limits characters.
